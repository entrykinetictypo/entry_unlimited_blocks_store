# 콘솔을 편하게 - Chrome Web Store edition

이 저장소는 `entry_unlimited_blocks` 원본을 그대로 보존한 채,
Chrome 웹 스토어 등록용으로 별도 관리하는 버전입니다.

## 원칙
- 원본 저장소는 수정하지 않습니다.
- 웹 스토어 버전에서는 언차티드 기능을 제외합니다.
- 심사에 문제가 될 수 있는 비공식 블록은 별도로 검토하여 제거합니다.
- 안전하다고 확인된 원본 기능만 선택적으로 동기화합니다.

## 현재 제외
- Uncharted / 언차티드 전체
- 언차티드 업데이트 확인
- Groq API 키 / 공유 키
- 언차티드 사용자 커스텀 코드 실행

> 비공식 블록 안전성 검토는 다음 단계에서 진행합니다.
